# emu-lab

A proposed MCP server for leasing isolated Android emulators, running reproducible tests, and collecting evidence for failure triage. It aims to keep parallel device work within host resource limits while protecting user-owned devices.

Part of [android-kit](https://github.com/fridaysundaymood/android-kit/blob/main/IMPLEMENTATION_PLAN.md); usable on its own.

## Status

**Planning only; not implemented yet.** See the [implementation plan](IMPLEMENTATION_PLAN.md) for scope, architecture, milestones, and testing strategy.

## Contributing

Contributions to the plan are welcome. Open an issue to discuss substantial changes or submit a pull request with a focused proposal. Use synthetic examples and fixtures rather than private application data or recordings.
